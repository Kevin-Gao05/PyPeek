# PyPeek 前端手工测试清单

> 按功能区域组织。每次改动后对照勾选。E2E 场景覆盖核心用户旅程。

---

## A. 欢迎弹窗 & 扫描流程

- [ ] 无缓存时首次启动 → 显示欢迎弹窗（隐私说明 + 两个按钮）
- [ ] 点击「开始扫描」→ 弹窗关闭 → 扫描开始 → 进度条显示 → 完成后渲染数据
- [ ] 点击「稍后再说」→ 弹窗关闭 → 空状态（无数据）
- [ ] 点击遮罩空白处 → 弹窗关闭
- [ ] 扫描中刷新按钮禁用 → 扫描完成后恢复
- [ ] 扫描完成后显示摘要行（盘符、文件数、耗时）
- [ ] 查看完成后摘要行在 1.5 秒后自动消失（非 onboarding 模式）

---

## B. 统计卡片 & 标签页

- [ ] 四张统计卡片显示正确数字（Python 数、venv 数、pip 缓存大小、总包数）
- [ ] 点击「Python 安装」卡片 → 跳转到 Python 标签页
- [ ] 点击「虚拟环境」卡片 → 跳转到 Venv 标签页
- [ ] 点击「pip 缓存」卡片 → 跳转到 pip 缓存标签页
- [ ] 标签页切换正常，各面板互斥显示
- [ ] 刷新按钮可重复使用（不累积事件监听器）

---

## C. Python 表格

- [ ] 表格列：版本、路径、来源、关联 venv、包数量、大小
- [ ] 来源正确标注（python.org / Microsoft Store / Conda / system / unknown）
- [ ] 「关联 venv」列显示数字 — 点击展开关联 venv 子列表
- [ ] 子列表中点击 venv 路径 → 跳转到 Venv 标签页并定位
- [ ] 点击行 → 展开包列表（右侧或下方出现包表格）
- [ ] 行再次点击 → 收起包列表
- [ ] 包列表的「返回」按钮 → 切回原标签页

---

## D. Venv 表格 & 重复环境

- [ ] 表格列：路径、Python 版本、来源 Python、大小、包数量、最后修改、操作
- [ ] 「来源 Python」列可点击 → 跳转 Python 标签页 + 高亮闪烁
- [ ] 子标签栏「全部」/「可能重复 (N)」在 venv 标签页激活时可见
- [ ] 「全部」显示所有 venv
- [ ] 「可能重复 (N)」只显示有 `duplicate_group` 的行，N 正确
- [ ] 重复组行有彩色左边框（同一组颜色一致）
- [ ] 无重复时显示「未发现重复环境」空状态
- [ ] 删除 venv → 弹窗确认 → 删除成功 → Toast 提示 → 表刷新
- [ ] 删除后重复组引用自动清理，单成员去标记

---

## E. pip 缓存

- [ ] 页面加载时显示 pip 缓存数据（或在扫描后显示）
- [ ] 柱状图正确渲染各分类的占比
- [ ] 「清理全部缓存」按钮 → 预览弹窗（大小、文件数）→ 确认后执行
- [ ] 单个分类「清理」按钮 → 预览 → 确认 → 清理成功
- [ ] 清理后缓存数据刷新

---

## F. 包浏览器 & 安全卸载

- [ ] 点击 Python 或 venv 行 → 展开包列表
- [ ] 包列表列：包名、版本、大小、简介、安全等级
- [ ] 安全徽章：绿色「安全」/ 橙色「警告」/ 红色「危险」
- [ ] 关键包（pip/setuptools/wheel/pkg_resources）显示「危险」徽章
- [ ] 点击「卸载」→ preview API 检查
  - [ ] safe → 确认弹窗 → 确认后卸载 → Toast 成功
  - [ ] warning → 依赖冲突弹窗（列 required_by）→ 强制确认 → 卸载
  - [ ] danger → 弹窗显示禁止 → 按钮禁用 → 无法卸载
- [ ] 卸载后包列表自动刷新

---

## G. Onboarding 教程

- [ ] 首次点击「开始扫描」→ 教程立刻启动（Step 1 展示统计卡片）
- [ ] Step 1 → 下一步 → Step 2（标签页栏）→ 自动切到 pythons 标签
- [ ] Step 2 → 下一步 → Step 3（扫描进度条）
- [ ] 扫描完成后 Step 3 自动跳 Step 4（高亮第一行）
- [ ] Step 4 → 下一步 → Step 5（安全徽章）→ 自动展开包列表
- [ ] Step 5 点击「完成」→ 教程退出，恢复正常状态
- [ ] 任意步骤「跳过」→ 退出教程
- [ ] Escape → 退出教程
- [ ] Header「?」按钮 → 有数据时重新进入教程 **不显示 Step 3**
- [ ] 「?」按钮无数据时 → Toast「请先完成一次扫描」
- [ ] Tooltip 不跳动、不溢出（各步骤定位正确）
- [ ] 遮罩半透明 + 目标元素脉冲边框高亮

---

- [ ] 子列表中 venv 路径可点击 → 跳转 venv 标签页
- [ ] Venv 表「来源 Python」可点击 → 跳转 Python 标签页
- [ ] 跳转后目标行有高亮闪烁动画（class `highlight-flash`）
