# 05 — 重复环境子标签

**What to build:** 虚拟环境标签页内新增子标签「全部」和「可能重复 (N)」，重复子标签集中展示带 `duplicate_group` 的环境，支持对比和删除。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 虚拟环境标签页内出现子标签栏：「全部」（默认选中）和「可能重复 (N)」（N 为重复组内环境总数）
- [ ] 切换到「可能重复」→ 表格仅显示 `duplicate_group` 非空的行，同一重复组的行在视觉上成组（同色边框/背景或组间分隔）
- [ ] 「可能重复」子标签无内容时（无重复环境），显示空状态提示「未发现重复环境」
- [ ] 重复视图中的每一行保留现有「打开文件夹」和「删除 venv」按钮，复用现有删除弹窗
- [ ] 删除重复环境后，若该重复组只剩一个成员，该成员从重复子标签中消失（回到「全部」视图）
- [ ] 子标签切换不触发重新扫描，纯前端过滤
- [ ] 子标签仅在虚拟环境标签页被激活时可见（不污染其他标签页布局）
