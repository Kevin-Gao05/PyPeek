# 02 — 首次启动弹窗 + 扫描摘要

**What to build:** 用户首次打开 PyPeek 时弹出隐私声明弹窗，一键开始扫描；扫描结束后在进度条下方展示摘要（盘符、文件数、耗时），让用户知道扫了什么。

**Blocked by:** 01（软依赖）— 建议先做 01，用 `load_cache()` 返回 `None` 判断首次启动。若独立实现，可临时用 `os.path.exists(cache_path)` 替代。

**Status:** ready-for-agent

- [ ] 首次启动（无缓存）弹出欢迎弹窗，声明「所有数据仅本地处理，不上传云端」及即将扫描的范围（PATH、注册表、盘符等）
- [ ] 弹窗提供「开始扫描」按钮（触发 `/api/scan`）和「稍后再说」按钮（关闭弹窗，保持空状态）
- [ ] 非首次启动不显示弹窗，直接进入主界面
- [ ] 扫描结束后，进度条下方出现摘要行：已扫描盘符（如 C: D:）、检查文件数、扫描耗时
- [ ] 摘要行在下次刷新或关闭后消失（不持久占据空间）
- [ ] 弹窗复用现有 Modal 组件样式，Escape / 点击遮罩可关闭（但首次启动强制显示）
