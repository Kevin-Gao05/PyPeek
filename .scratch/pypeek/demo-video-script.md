## 完整文案

### 开场（0:00-0:15）

> **旁白**：Windows 上搞 Python，装了多少个解释器？虚拟环境散落在哪些盘？pip 缓存占了多大地方？PyPeek — 双击即开，一眼看全。

| 画面  | 操作                         |
| --- | -------------------------- |
| 桌面  | 双击 `start.bat`，PyPeek 窗口弹出 |

---

### 首次启动（0:15-0:35）

> **旁白**：首次运行弹出欢迎页，明确告诉你：所有数据只在本地处理，不上传任何云端。点击「开始扫描」，进度条实时推进。

| 画面   | 操作                       |
| ---- | ------------------------ |
| 欢迎弹窗 | 镜头停留 2 秒，展示隐私说明和扫描范围     |
| 扫描过程 | 点击「开始扫描」，进度条从 0% 跑到 100% |

---

### 扫描结果（0:35-1:00）

> **旁白**：扫描完成后，顶部四张统计卡片一目了然——几个 Python 安装、几个虚拟环境、pip 缓存多大、总计多少包。摘要行告诉你扫了哪些盘、检查了多少条目、耗时几秒。

| 画面   | 操作                                         |
| ---- | ------------------------------------------ |
| 统计卡片 | 逐张卡片给特写：Python 数、venv 数、缓存大小、总包数           |
| 摘要行  | 镜头移到摘要行：`已扫描 C: D: │ 检查 12 个条目 │ 耗时 3.2 秒` |

---

### Python 安装（1:00-1:20）

> **旁白**：「Python 安装」标签页列出所有解释器。版本号、完整路径、来源——python.org 还是 Microsoft Store——一目了然。同版本多实例自动标记重复。

| 画面        | 操作                          |
| --------- | --------------------------- |
| Python 表格 | 逐列展示：版本号加粗、路径、来源徽章、包数量、占用空间 |
| 重复标记      | 镜头落在黄色「重复」徽章上               |

---

### 虚拟环境（1:20-1:40）

> **旁白**：切到「虚拟环境」标签，全盘搜索 `pyvenv.cfg` 的结果都在这里。路径、Python 版本、来源解释器、占用空间、最后修改时间。不需要的 venv 点一下直接删，三道安全检查兜底。

| 画面      | 操作                                |
| ------- | --------------------------------- |
| venv 表格 | 展示列表 + 列信息                        |
| 删除操作    | 点击删除按钮 → 确认弹窗 → 点击确认 → Toast 提示成功 |

---

### 包浏览器（1:40-2:10）

> **旁白**：点击任意 Python 或虚拟环境行，进入包列表。包名、版本、大小、简介。每个包标了安全等级——绿色安全、黄色有依赖冲突、红色系统关键禁止卸载。

> 点「卸载」走三段式流程：先 dry-run 预览安全等级，确认后执行。如果其他包依赖它，弹窗列明影响范围，强制卸载需显式确认。pip、setuptools 等关键包无条件拒绝。

| 画面   | 操作                                   |
| ---- | ------------------------------------ |
| 包列表  | 点击一行展开，滚动展示包列表 + 安全徽章                |
| 安全卸载 | 点卸载 → 弹窗展示安全检查 → 确认 → Toast 成功       |
| 依赖冲突 | 点一个有依赖的包 → 弹窗列出 `required_by` → 强制卸载 |

---

### pip 缓存（2:10-2:40）

> **旁白**：切到「pip 缓存」标签。柱状图直观对比各类缓存占用——下载缓存、本地编译缓存、自检记录。每个分类右侧有清理按钮，点一下走 preview 预览、确认后执行，释放磁盘空间。也可以一键清理全部缓存。

| 画面    | 操作                                      |
| ----- | --------------------------------------- |
| 缓存柱状图 | 镜头扫过分类柱状图 + 汇总信息                        |
| 清理单个  | 点击某分类「清理」→ 弹窗显示大小/文件数/风险提示 → 确认 → Toast |
| 清理全部  | 点击「清理全部缓存」→ 弹窗汇总所有分类 → 确认 → 面板刷新显示空状态   |

---

### 收尾（2:40-3:00）

> **旁白**：PyPeek — Python 环境桌面浏览器。纯 Python 标准库，零 Web 框架。GitHub 开源，MIT 协议。链接在简介里，给个 Star 支持一下。

| 画面        | 操作                                       |
| --------- | ---------------------------------------- |
| 全屏 PyPeek | 快速切几个标签页，展示流畅感                           |
| 结束画面      | 屏幕正中：PyPeek logo + GitHub URL + Star CTA |
