## 版本三：日記叙事（适合 Thread）

我一直不知道自己 Windows 机器上散落了多少个 Python。

python.org 装的、Microsoft Store 装的、venv 建完忘了删的、pip 缓存占了好几 G……

于是花了两天写了个小工具：PyPeek。

它做了什么：

1. PATH + 注册表双重扫描，找出所有 Python 安装，标记来源和重复
2. 全盘搜 pyvenv.cfg，列出所有虚拟环境，路径/大小/包数量/最后修改时间
3. pip 缓存分类柱状图，按分类一键清理
4. 包浏览器展开即看，安全等级三色标注
5. 卸载走 dry-run → 确认 → 执行，依赖冲突弹窗列明影响范围，关键包无条件拒绝

技术选择：零 Web 框架，纯标准库 ThreadingHTTPServer + pywebview 桌面壳。前端纯 HTML/CSS/JS，Swiss 设计系统。

GitHub: github.com/Kevin-Gao05/PyPeek
