# PyPeek 实机测试流程

> 在 Windows 10/11 实机上完整验证所有功能模块。

---

## 1. 环境准备

### 1.1 前置条件

- [ ] Windows 10 或 Windows 11
- [ ] 已安装至少两个 Python 版本（例如 python.org 3.12 + 3.11）
- [ ] 已创建 1-2 个虚拟环境（`python -m venv test_env`）
- [ ] pip 缓存中有一定的下载记录（`pip install flask numpy pandas` 跑一下再删掉留下缓存）
- [ ] （可选）安装了 Microsoft Store 版 Python 或 Conda

### 1.2 拉取代码

```bat
cd %USERPROFILE%\Desktop
git clone https://github.com/Kevin-Gao05/PyPeek.git
cd PyPeek
```

### 1.3 确认版本

```bat
git log --oneline -1
:: 应该看到: ee067ba  安全卸载: ... (#8)
```

## 5. 与 WSL2 开发环境的差异

以下是 WSL2 中无法测试、必须在 Windows 实机上验证的点：

| 差异点 | 说明 |
|--------|------|
| Windows 注册表扫描 | `scanner/pythons.py` 使用 `winreg`，WSL 中无注册表 |
| Microsoft Store Python 识别 | 路径含 `WindowsApps` → 仅在 Windows 上有 |
| pywebview 桌面窗口 | WSL 无 GUI，只能用浏览器测试后端 |
| `start.bat` 双击启动 | 文件资源管理器中的行为 |
| 盘符扫描 (C:\, D:\) | `scanner/venvs.py` 全盘搜索，WSL 中走的是 Linux 路径 |
| Windows 路径格式 | `/` vs `\`，路径分隔符已在代码中用 `os.path` 处理 |
| 权限问题 | Windows 上 `C:\Program Files\` 可能需要管理员权限读取 |

## 6. 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| `python` 不是内部命令 | Python 未加入 PATH | 重装 Python 勾选 "Add to PATH" |
| pywebview 安装失败 | 缺少 Windows GUI 依赖 | 确保是 Windows 原生 Python，非 WSL |
| 扫描卡住不动 | 正在扫描大目录（全盘搜索 venv） | 等待 30 秒，查看日志 |
| pip 缓存不显示 | 缓存为空 | 跑 `pip install flask` 再 `pip uninstall flask -y` |
| 展开行报红色错误 | `pip show` 超时 | 检查网络/pip 配置 |
| 卸载按钮没反应 | JS 错误 | 打开浏览器控制台（如果用浏览器模式）查看报错 |
